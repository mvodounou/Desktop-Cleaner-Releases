Privacy Policy

Last updated: 2026-09-24

Short version: Desktop Cleaner collects nothing beyond what a purchased license genuinely requires. It's a Mac utility that finds and removes cache files, memory pressure, large files, and leftover app data — entirely on your own Mac. Scanning and reviewing results never touches the network at all. The only things that do are three narrow, specific requests, each described in full below: checking for app updates, sending a crash report you've explicitly chosen to send, and activating or validating a paid license.

Information We Collect

Nothing, automatically. Specifically, Desktop Cleaner does not collect, store, or transmit, without your explicit action:

  • Your name, email address, or any other personal identifier
  • Usage analytics or behavioral data (what you clicked, which features you use, how often you open the app)
  • The contents of your files, or a list of what you chose to delete
  • Your device's advertising identifier, IP address, or location
  • Any information via cookies, web beacons, or similar tracking technology — the app has no web views and makes no web requests

There is no sign-up, no login, and no account of any kind beyond the license key described below. Three features make network connections, and only these three: checking for app updates, opt-in crash reporting, and license activation. None of the three runs silently collecting behavioral data — you can verify this yourself with a network monitor (Little Snitch, or macOS's own Console app), which will show no activity from Desktop Cleaner outside of those cases.

Crash reports are opt-in, one at a time. If Desktop Cleaner crashes, macOS itself (not Desktop Cleaner) saves a local crash log, the same way it does for every other app on your Mac. The next time you open Desktop Cleaner, it shows you that log and asks whether you'd like to send it — you can read the entire report first, and nothing is sent anywhere unless you click "Send Report." If you do, that one report (the stack trace, your macOS version, and the app's version — never your files or any personal data) is sent to Sentry, a third-party crash-reporting service. Declining, or simply not clicking "Send Report," means nothing is sent, ever, for that crash.

Cleaning anything up requires a paid license; scanning and reviewing never does. Activating a license sends the key you enter, plus a label for this Mac (its computer name, e.g. "Jane's MacBook Pro" — the same name already visible to you in System Settings → General → Sharing), to LemonSqueezy, the service used to sell and validate licenses. LemonSqueezy also receives this same information once each time the app launches with a license already activated, to confirm the license is still valid. Your license key is stored in this Mac's Keychain, not in a plain-text file. No other information about your Mac or your files is included in either request.

How the App Works Locally

To do its job, Desktop Cleaner reads information that already exists on your Mac — but only to show it to you and act on your explicit choices, and only in memory while the app is running:

  • File and folder metadata (paths, sizes, modification dates) under locations like ~/Library/Caches, ~/Library/Logs, and your home folder, to find caches, logs, and large files worth reviewing.
  • Installed application info (names, bundle identifiers, icons, versions) read from /Applications, used by the Uninstaller to find an app's related files.
  • Running process names and memory usage (via the same mechanism Activity Monitor uses), shown in the Memory tab's "Top Processes" list.

None of this is written to a log file, bundled into a report, or sent anywhere. It's read fresh each time you open a tab or trigger a scan, held in memory for as long as the app needs it, and discarded when you quit. Files you choose to delete are moved to the Trash (recoverable by you, like any other Finder deletion) or, for system-level categories that require administrator approval, removed permanently after you explicitly confirm — either way, nothing about what you deleted is recorded or reported.

Permissions We Ask For

Full Disk Access (System Settings → Privacy & Security). This lets scans reach folders macOS otherwise blocks apps from reading, like Photos Library or other apps' protected data, so results are more complete. It's entirely optional — the app works without it, just with narrower results — and macOS itself, not Desktop Cleaner, controls who can grant or revoke it.

Administrator password prompt. Some cleanup categories (system-wide caches, rotated system logs, Time Machine local snapshots) are owned by the operating system rather than your user account, so macOS requires administrator approval to remove them. Desktop Cleaner never displays a password field, never receives what you type into that dialog, and has no way to store or transmit it even if it wanted to.

Third-Party Services

Desktop Cleaner does not integrate any third-party analytics or advertising SDKs, and does not run any crash-reporting SDK that captures data automatically in the background. Three network connections exist, all narrow and all described above:

  • Update checks, which only ever check a version number against a public release feed. They never send information about you or your Mac.
  • Crash reports, sent to Sentry, but only for a specific crash you have reviewed and explicitly chosen to send.
  • License activation and validation, sent to LemonSqueezy — your license key and this Mac's computer name, nothing else.

No other data is shared with any third party. If a future version adds a feature that involves a new kind of network connection, this policy will be revised first, with the change clearly called out, before that version ships.

Children's Privacy

Desktop Cleaner is a general-purpose system utility, not directed at children, and isn't designed or marketed for use by them. Because the app collects no data from any user regardless of age, there is no children's personal information for us to knowingly or unknowingly gather.

Changes to This Policy

If this policy changes, the "Last updated" date at the top will change with it, and any meaningful change — particularly anything that would add data collection where none exists today — will also be called out in that app version's release notes, not just buried in this page.
