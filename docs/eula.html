What the Software Does

Desktop Cleaner scans locations on your Mac for cache files, logs, large files, duplicate files, and leftover application data, and removes items you explicitly select — either by moving them to the Trash, or, for a small number of system-level categories, by deleting them permanently after you approve a macOS administrator password prompt. Exactly what's removed and how is entirely under your control: nothing is selected or deleted without your action. Details on what data the Software reads (and that it collects none of it) are in the Privacy Policy.

Your Responsibility for What Gets Deleted

The Software's entire purpose is deleting files, so please read this section carefully.

  • You choose what's removed. Every category and every file the Software can act on is something you selected — review your selections before confirming.
  • Trash-based removal is reversible until you empty the Trash. Most categories work this way.
  • System-level removal, behind an administrator password prompt, is permanent. A small number of categories (shared system caches, system logs, Time Machine local snapshots) work this way, clearly marked in the app as requiring a password.
  • We strongly recommend keeping a current backup of anything important (Time Machine or otherwise) before using any file-deletion tool, this one included. If you select and remove a file you needed, we are not able to recover it for you.
